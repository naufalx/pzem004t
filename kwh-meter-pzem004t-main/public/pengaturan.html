RESET REGISTER ENERGI (KWH)

Atur ulang acuan pembacaan akumulasi energi (kWh) pada antarmuka dashboard ke 0.000 kWh.

Catatan: Tindakan ini mengalibrasi baseline pembacaan sesi di browser lokal Anda. Untuk mereset register chip fisik PZEM-004T, gunakan perintah CLI simulator atau tombol kalibrasi hardware pada modul sensor.

ZONA BAHAYA: RESET DATABASE RIWAYAT CLOUD

Hapus seluruh catatan telemetri, rekaman batch, dan ringkasan konsumsi energi di Google Firebase Realtime Database.

Perhatian: Tindakan ini permanen. Seluruh rekaman riwayat dan ringkasan energi di cloud database akan dihapus bersih (status konektivitas perangkat tetap dipertahankan).
