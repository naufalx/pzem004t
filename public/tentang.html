PERINGATAN TEGANGAN TINGGI: Sisi AC modul PZEM-004T terhubung ke listrik PLN 220V. Isolasi optocoupler galvanik internal 1kV wajib dijaga demi keselamatan sirkuit DC ESP32.

IoT Smart KWH Meter (ESP32 + PZEM-004T v3.0)

Sistem pemantauan energi listrik AC 1-fasa berbasis mikrokontroler ESP32 dan sensor presisi tinggi PZEM-004T v3.0. Perangkat beroperasi secara mandiri (100% autonomous), cukup dihubungkan dengan daya listrik dan jaringan WiFi, tanpa memerlukan komputer pendukung (PC) di lokasi.

Data telemetri diambil setiap 1 detik, di-buffer dalam RAM mikrokontroler, dan dikirim secara terkelompok (HTTPS POST batch) setiap 5 detik ke Vercel Serverless Functions. Data kemudian disinkronkan secara instan ke antarmuka web melalui Google Firebase Realtime Database.

1. SPESIFIKASI PERANGKAT KERAS (HARDWARE)

MikrokontrolerESP32 WROOM-32D DevKit v1 (Xtensa Dual-Core 32-bit LX6 240MHz, 520KB SRAM, 4MB Flash)
Modul SensorPeacefair PZEM-004T v3.0 TTL dengan Current Transformer (CT) koil 100A
Pengkabelan Serial (UART2)GPIO16 (RX2 ESP32 ← TX PZEM), GPIO17 (TX2 ESP32 → RX PZEM), VCC 5V DC, GND
Baud Rate Serial9600 bps, 8 Data bits, No parity, 1 Stop bit (8N1)
Rentang Pengukuran ACTegangan: 80 s.d. 260 VAC | Arus: 0 s.d. 100 A | Daya Aktif: 0 s.d. 23 kW | Frekuensi: 45 s.d. 65 Hz | PF: 0.00 s.d. 1.00 | Energi: 0 s.d. 9999 kWh
Keamanan & Isolasi ListrikOptocoupler galvanik internal 1kV pada modul PZEM (sisi tegangan tinggi AC 220V PLN terisolasi dari sirkuit DC mikrokontroler)

2. FIRMWARE & MANAJEMEN DATA (PLATFORMIO C++)

Framework FirmwarePlatformIO C++ (Arduino Core for ESP32)
Sampling & BatchingSampling PZEM tiap 1000 ms, pengiriman batch 5 rekaman per 5 detik
Ketahanan Jaringan (Offline Buffer)Ring Buffer RAM 1000 rekaman (mencegah data hilang saat WiFi terputus sesaat)
Sinkronisasi WaktuNTP (Network Time Protocol: pool.ntp.org), Waktu Indonesia Barat (WIB / UTC+7)

3. CLOUD BACKEND & DATABASE REALTIME

Cloud PlatformVercel Serverless Functions (Node.js ESM)
Database TargetGoogle Firebase Realtime Database (Region: asia-southeast1, Singapura/Jakarta)
Streaming Antarmuka WebFirebase Web SDK Event Push (onValue) dengan Watchdog Dinamis 15s
Ekspor LaporanCSV Standar RFC 4180 dengan UTF-8 BOM (\uFEFF) untuk kompatibilitas penuh Microsoft Excel

4. ANTARMUKA PENGGUNA (FRONTEND WEB)

Teknologi WebVanilla HTML5 Semantic, Modern CSS Custom Properties, ES6 Modules, HTML5 Canvas Chart
Standar Desain & TipografiVercel Design System, Geist & Geist Mono Typography, Tabular Numerals (tabular-nums), Kontras WCAG AA
Responsivitas LayarMobile-First Responsive Design, dioptimasi penuh mulai resolusi terkecil (320px) hingga layar 4K
